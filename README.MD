# 🏋️‍♂️ GymCheck

> **"Treine. Registe. Evolua."**

O **GymCheck** é uma aplicação (Progressive Web App - PWA) desenvolvida para simplificar a gestão de treinos, monitorização nutricional e acompanhamento da evolução corporal. O projeto foi desenhado para oferecer uma experiência fluida, rápida e sem interrupções durante o treino na academia.

---

## 🎯 Sobre o Projeto

Este repositório foi criado para **fins acadêmicos e de estudo**, com o objetivo de aplicar na prática conceitos avançados de desenvolvimento software, incluindo:
* Arquitetura em camadas com **Spring Boot**.
* Mapeamento objeto-relacional (ORM) e consistência de dados.
* Segurança e autenticação de usuários com **Spring Security**.
* Prototipagem rápida de interfaces modernas (UI/UX)
⚠️ **Status do Projeto:** 🛠️ *Em construção / Desenvolvimento ativo.*

---

## 📱 Prototipagem e Design (Vercel)

Para garantir uma interface inovadora, longe de modelos genéricos e totalmente focada na experiência do usuário em telas menores, o design do sistema foi **previamente prototipado e validado via Vercel / Tailwind CSS**.

🔗 **Acesse o Protótipo do Design:** [https://gymcheck-ecf.vercel.app/](https://gymcheck-ecf.vercel.app/)

---

## 🛠️ Tecnologias Utilizadas

### **Backend**
* **Java 17+**
* **Spring Boot 3**
* **Spring Data JPA** (Persistência e repositórios)
* **Spring Security** (Autenticação e controle de acesso)
* **Database:** H2 Database (Desenvolvimento/Testes) / PostgreSQL (Produção)

### **Frontend & UI/UX**
* **Thymeleaf** (Renderização dinâmica no servidor)
* **Tailwind CSS** (Framework CSS utilitário via CDN/Custom)
* **PWA (Progressive Web App)** (Recursos mobile nativos)
* **Bootstrap Icons / Lucide Icons**
